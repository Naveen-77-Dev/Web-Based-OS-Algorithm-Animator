Disk Scheduling Algorithms

What is Disk Scheduling?

Disk scheduling is the process of deciding the order in which disk I/O requests are serviced. The main objectives are to minimize seek time, maximize disk bandwidth, and ensure fairness.

Available Algorithms:

First Come First Serve (FCFS)

The simplest approach that serves requests in the order they arrive. While fair, it may result in higher seek times and disk arm movement.

SCAN (Elevator)

The disk arm moves in one direction servicing requests until it reaches the end, then reverses direction. This reduces the maximum waiting time for requests.

C-SCAN (Circular SCAN)

Similar to SCAN, but the arm only services requests in one direction. When reaching the end, it quickly returns to the beginning without servicing requests.

LOOK

An improved version of SCAN where the arm only goes as far as the last request in each direction, then reverses.
