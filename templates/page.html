Page Replacement Algorithms

What is Page Replacement?

Page replacement algorithms decide which memory pages to remove when a new page needs to be loaded into memory that is already full. The goal is to minimize page faults and maximize memory utilization.

Available Algorithms:

First In First Out (FIFO)

The oldest page in memory is replaced. Simple to implement but may not always provide optimal performance.

Least Recently Used (LRU)

Replaces the page that hasn't been used for the longest time. Generally provides better performance than FIFO but requires tracking page usage.

Optimal

Replaces the page that won't be used for the longest time in the future. This is theoretical and provides the best possible performance, but isn't implementable in practice as it requires knowledge of future page requests.
